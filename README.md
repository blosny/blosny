I am a final-year Computer Engineering student at **Fırat University**, passionate about building scalable microservices, resilient distributed systems, and cloud-native infrastructure.

## Featured Projects

### [Parallax DevOps Platform](https://github.com/blosny/parallax-devops-platform)
> **6-week DevOps internship project on a local Kubernetes cluster**
- Packaged two services with Helm, secured service-to-service traffic with Istio mTLS, and added API key authentication and rate limiting with Kong.
- Set up GitHub Actions CI, ArgoCD GitOps deployment, Prometheus/Grafana monitoring and Argo Rollouts canary releases.
- **Tech Stack:** Docker, Kubernetes (Minikube), Helm, Istio, Kong, ArgoCD, Prometheus, Grafana, Argo Rollouts.

### [ServicePulse](https://github.com/blosny/ServicePulse)
> **AI-Powered Microservice Observability Platform**
- Designed a reactive health-monitoring engine using **Spring WebFlux** and **Hexagonal Architecture**.
- Integrated **Google Gemini AI** for automated root cause analysis and incident resolution guides.
- **Tech Stack:** Java 21, Spring Boot, WebFlux, Docker Compose, PostgreSQL, GitHub Actions, Gemini AI API.

### [Verifiable Local RAG](https://github.com/blosny/verifiable-local-rag)
> **Privacy-First Offline Document Intelligence Engine**
- Built an offline RAG pipeline for Q&A over local documents, running a local model with Microsoft Foundry Local SDK.
- Checks each sentence of the answer against the source text (Jaccard overlap score) to flag unsupported claims.
- **Tech Stack:** Python, Microsoft Foundry Local SDK (Qwen2.5), SQLite vector storage, Streamlit.

### [LogScope](https://github.com/blosny/LogScope)
> **Centralized Log Collection & AI Exception Analysis Platform**
- Full-stack centralized log management system with Gemini AI root cause analysis dashboard.
- **Tech Stack:** Java 17, Spring Boot, Hexagonal Architecture, Gemini AI, Tailwind CSS.

### [Acaba Ne Yesem](https://github.com/AcabaNeYesem)
> **Recipe Search Engine & Mobile Startup Backend**
- Engineered backend for recipe discovery managing 10,000+ items with hybrid search (exact + near match).
- **Tech Stack:** Python, FastAPI, PostgreSQL, Gemini API.
